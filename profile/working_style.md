## 跨机器工作模式

### 共享大脑同步

使用 GitHub 仓库 `Doo-ai-brain` 作为两台机器之间的知识桥梁。

**台式机（主力）→ 仓库**：
- 完成重要任务后执行 `/brain-sync`
- Agent 总结 → 更新 Markdown → git push

**笔记本 → 仓库**：
- 开始工作前 `git pull` 获取最新知识
- 同样可以贡献经验并 push 回来

**关键原则**：
- 不是所有任务都需要同步，只记录有长期价值的内容
- 仓库是知识库，不是日志或聊天记录
- 纯 Markdown，不绑定任何特定 AI 工具
