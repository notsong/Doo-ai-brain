## 核心公式（GB/T 6394-2017）

| 公式 | 说明 |
|------|------|
| `G = -6.643856 × lg(Ī_mm) - 3.288` | 平均截距(Ī, mm) → 晶粒度级别 |
| `Ī(全局) = ΣL_T / ΣP` | B.5 合并统计（多视场） |
| `ΔG = 6.643856 × lg(1 + %RA/100)` | B.6 晶粒度不确定度（±值） |
| `l(G) = 20 × 2^(4 - G/2)` μm | 级别→平均截距（经验验证：G=5→56.6μm, G=8→20μm, G=14→2.5μm） |
| `G(A) = 8 - 2·log2(0.886·√A/20)` | 单晶粒面积(μm²)→级别（等效圆换算，与报告级别列一致） |

级别每差 1 级，平均截距差 2^(1/2) ≈ 1.414 倍；半级差 2^(1/4) ≈ 1.189 倍。

## 面积法（JLDAnalysis_Area.cs / GrainSizeAreaMethod.cs）

- **圆形视场**：直径固定 798 μm（对应 100× 放大标准视场），圆心默认图片中心，模拟显微镜目镜视场，避免图片边缘不完整晶粒影响统计

- 兼容性：`FovCenter`/`FovRadiusPx` 用可空参数（默认 null），不传时行为不变（BLT/DHTG/IMC 等 8 个模块零影响）

### 面积法全局统计：相对误差 %RA 与置信区间 ΔG（2026-08-23）

与截点法 B.2-B.6 对称的实现（HQL `JLDAnalysis_Area.cs` 408 行，DHTG 移植同款）：

- **公式**：`G = 3.321928 × lg(N_A) - 2.954`（N_A = 单位面积晶粒数 个/mm²，代码 = `EffectiveGrainCount / 视场面积mm²`；手写式 `m²N/A` 与之等价，代码用像素标定换算无需显式放大倍数）
- **统计对象 = 每张图的 N_A**（不是 G，与截点法统计 Ī 而非 G 对称）：n 张图 → 样本标准差 s(n-1) → t 查表 95%CI = t·s/√n（n<5→2.776、n>20→1.96）→ `%RA = ci95 / mean × 100`
- **ΔG = 3.321928 × lg(1 + %RA/100)**（面积法系数；截点法用 6.643856 因其 G = -6.643856·lg(Ī)，lg 系数是 2×3.321928）
- **收集条件**：NA>0 的图才参与（对称截点法 P>0）；n=1 → %RA=0；无有效图 → 两字段输出 0
- **输出字段**（results.ai，用户拍板严格只加这俩）：`global_relative_error`、`global_confidence_interval`

## 珠光体晶粒度（JLDAnalysis_ZGT.cs，LWGT 模块）

珠光体+铁素体双相组织中，截点若穿过珠光体区域会得到虚假的"超长截距"，需过滤：

```
相分割(1003/010) → 白=珠光体 → 过滤小面积块(>50px) → 膨胀1px →
  ① 珠光体区域内晶界线抹掉（不产生假截点）
  ② 逐弧采样：弧落在珠光体内的长度占比 > 80% 才剔除（不计 P、不计 L_T）
→ Ī = 保留弧长和 ÷ 保留弧数 → 评级
```

关键参数（踩坑调整史）：
- 膨胀从 3px → **1px**（3px 会把相界面附近有效晶界也抹掉，剔除过多）
- 判定从"碰到就剔"→ **占比 > 80% 才剔**（一票否决式剔除过多）
- 珠光体块面积 **> 50 像素**才参与弧对比（滤掉小噪点）
- 相分割失败时自动回退到不过滤原逻辑
- 可视化：保留截点黄色、剔除弧绿色、辅助圆保留弧蓝色/剔除弧绿色
- 输出：`pearlite_ratio`（单图）、`average_pearlite_ratio`（全局）

## 双重晶粒度双峰拟合（2026-08 验证）

双重晶粒度（混晶）= 大小明显不同的两群晶粒。常规平均评级会被粗细中和，须分别评定两群级别 + 面积占比。

### 数据预处理
- 剔除面积 < 2 μm² 的疑似分割碎屑
- 11 级以上晶粒数据不准确 → 只统计 ≤11 级（11 级以上面积占比合计 < 0.5%，影响可忽略）

### 方法：级别轴双高斯拟合（最终方案）
1. 按 0.5 级步长统计各级**面积占比 a%**、个数占比 c%
2. 以面积占比为直方图高度，在级别轴上 EM 拟合两个高斯分量
3. **σ 上限约束 ≤ 0.7 级**（防止分量过宽互相吞并；连续过渡型数据必须，天然分离型无影响）
4. 两个高斯均值 = 大/小晶粒代表级别；分量比例 = 面积占比；级别差 ≥ 3 级 → 双重晶粒度

### 为什么权重用面积占比
大晶粒面积占优个数不占优、小晶粒个数占优面积不占优。综合权重 √(面积×个数) 会把两群质心互相拉回（结果偏大）；面积加权让两群自然分离。

## 附录：个数占比 vs 面积占比的权重关系（2026-08-07）

### 核心关系式
对每个级别 i：**a_i = c_i × (Ā_i / Ā_global)**

- a_i = 该级面积占比，c_i = 该级个数占比，Ā_i = 该级平均晶粒面积，Ā_global = 全局平均晶粒面积
- 大晶粒级（Ā_i > Ā_global）：a > c（面积占优）；小晶粒级：a < c（个数占优）
- **a = c 的交点级别 = 平均晶粒面积对应的级别**（图2 实测交点 8.5 级，全局平均 361.5 μm²）
- 推论：个数分布和面积分布不是独立信息——知道个数分布+各级平均面积即可推出面积分布

### 三种权重方案对比（图2 实测）
| 方案 | 公式 | 大/小晶粒 EM 结果 | 问题 |
|------|------|------|------|
| 个数权重 | w=c | 7.08 / 9.94 (19%/81%) | 细晶 81% 票数淹没粗群，大晶粒偏细 |
| **面积权重（采用）** | w=a | **5.97 / 9.15 (57%/43%)** | 大晶粒定位准，小晶粒靠总面积仍可找到 |
| 几何平均 | w=√(a·c) | （k-means 实验）7.3/10.2 | 两群质心互相"中和"，无法分离 |

几何平均可改写为：√(a_i·c_i) = c_i × √(Ā_i/Ā_global)——个数权重 × 面积优势的平方根，两头都打折。

### EM 拟合面积分布的本质
E-step 中每个级别点按面积占比 a_i 参与两高斯投票，等价于**每个晶粒按自己的面积大小投票**——大晶粒投粗群、小晶粒投细群，群内面积越大权重越高。这正是"大晶粒面积占优、小晶粒个数占优"的自然编码。

### 推论：面积峰与个数峰的距离
晶粒面积近似对数正态时，面积分布峰比个数分布峰向粗端偏移约 σ²（log 尺度）。**双重晶粒度越严重（分布越宽），两峰离得越远**——第二批界面/条带试样（σ 大）两峰相距 5 级，第一批（σ 受约束）相距约 3 级。面积EM与个数EM 的 μ₁ 差距可作为混晶严重程度的量化指标。
